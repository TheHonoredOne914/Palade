Key Features

What makes Palade different from traditional AI coding assistants

🔍

Triage

Scans your repository and ranks files by risk (churn, centrality, naming heuristics) so the token budget goes where the bugs live.

🐝

Swarm

Up to 8 distinct agents run concurrently over the same code, each with its own domain expertise: Security, Architecture, Performance, Maintainability, Dead Code, Test Intelligence, Pragmatism, and Logic.

⚖️

Verdict

When two agents disagree about the same lines, an arbitration engine resolves the conflict and records the decision as an ADR.

📋

Synthesis

Merges, deduplicates, and compiles everything into a prioritized executive summary with ROI estimates — as interactive HTML, JSON, and Markdown.

🎭

Review Modes

Standard, security, onboard, debt, and ghost modes for different review scenarios.

👁️

Watch Mode

Always-on review daemon that watches your files and re-runs the full agent swarm the moment code changes.

Quick Start

Get up and running in minutes

# Install globally npm install -g palade # Initialize in your project (creates .palade/palade.config.ts) palade init # Launch the interactive TUI palade # ...or run a review straight from the CLI palade review

Requires Node.js ≥ 20. Works with 100% free-tier providers out of the box.

The Agent Swarm

Eight specialized agents working in parallel

🔐

Security

Hunts for injection, broken auth, hardcoded secrets, missing input validation, weak cryptography

🏛️

Architecture

Hunts for circular dependencies, layer violations, tight coupling, God objects

🚀

Performance

Hunts for N+1 queries, unbounded loops, missing caching, sync-in-async

🧹

Maintainability

Hunts for duplication, naming problems, undocumented complexity

💀

Dead Code

Hunts for unused exports, zombie routes, unwired classes, stale TODOs

🧪

Test Intelligence

Hunts for untested critical paths, hollow mocks, missing edge cases

⚖️

Pragmatism

Hunts for cost/benefit tradeoffs — what's worth fixing now vs. deferring

🧮

Logic

Hunts for business-logic correctness, state-machine violations
